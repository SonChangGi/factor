# 고정 팩터 조회와 차트 개선

## 동작

- `단일 팩터`에서 통합 32개 정의를 선택한다. 26개 투자 정의는 원래 전체 기간의 비용 후 NAV·낙폭·지표를 표시한다. 연구 전용 6개는 투자 성과·보유를 만들지 않는다.
- `신호월`은 해당 월말 신호의 다음 체결 종가 실제 보유를 조회한다. 현재 보유, 체결 목표, 마지막 정상 평가일을 구분한다. 팩터와 신호월은 URL과 뒤로 가기에서 복원한다.
- 차트의 값·점·날짜는 커서 위치를 따르며 같은 화면의 수익률·낙폭에 같은 관측일을 적용한다. 클릭·터치·키보드로 고정하고 Escape로 최신 관측일로 돌아간다. 관측일은 보유 신호월을 변경하지 않는다.
- 비중 내림차순 보유 표는 PC에서 10종목씩 두 열, 모바일에서 10종목씩 이전·다음으로 조회한다. 기존 색상·서체·패널·SVG 표현을 사용한다.

월별 내역은 별도 `data/fixed-factor-history.json`으로 추가하고 필요할 때 읽는다. 고정 입력·원래 17개 계산 소스 해시를 확인한 뒤 26개 고정 팩터만 순차 재생했다. 모든 팩터의 NAV·낙폭·전체 지표·최종 종목별 비중·현금·수취권을 원래 결과와 정확히 비교한 후 3,354개 월별 기록을 내보냈다. 기존 월별 선택·연구·민감도 결과는 다시 계산하거나 수정하지 않았다.

내역 추출기와 보유 해석 함수의 해시는 publication manifest에 별도 기록한다. 새 코드를 과거 결과의 계산 코드로 재표기하지 않는다. 이후 새 계산은 동일한 공통 회계를 사용해 고정 팩터별 내역을 결과에 포함하고 이 함수를 계산 코드 해시에 추가한다.
