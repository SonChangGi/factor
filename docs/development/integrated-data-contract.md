# 통합 데이터 계약

최종 로컬 입력은 `outputs/integration/market-2026-10-19-quality`이며, 입력 ID는 `ca0c4b32d9c8892d41ca41e64de689642a1b63d1c142fc2f115f5b3fb0b33f5c`다. 무료 Yahoo Finance 자료를 사용하며 2010-01-04부터 2026-10-16까지 4,223거래일을 담는다. 외부 배포와 운영 예약은 이 계약의 변경 대상이 아니다.

## 유니버스와 처리 순서

2026-10-16 공개 실행의 요청 목록을 동결했다. Momentum 2,865종목과 Best 1,766종목의 교집합은 1,671종목이며, 합집합은 **2,960종목**이다. Best에서 추가된 종목은 95개다. SPY·QQQ·Nasdaq 지수는 별도 비교용 세 열이며 투자 적격성은 항상 거짓이다.

[유니버스 원장](../../momentum_factor_lab/resources/integrated_universe.json)은 공급자 ticker, 프로젝트별 포함 여부, 식별자 정규화와 공개 목록의 URL·SHA-256을 보존한다. 현재 2,960개 식별자는 이미 Yahoo 형식이며 중복 변환이 없다. 기존 Momentum 목록의 종목 분류를 계승하고, 추가 종목의 미확인 분류는 임의로 확정하지 않는다.

```text
무료 공급자 OHLCV·조정종가·분할·배당
→ 다운로드 원본과 수집 영수증
→ 거래 당시 가격·거래량 복원
→ 동결 합집합과 날짜별 투자 적격성
→ OHLC 품질 마스크와 팩터별 입력 적격성
→ 팩터 계산·순위 → 공통 거래·회계 → 연구 및 화면 결과
```

공통 적격성은 거래 당시 종가 $5 이상, 가격 관측 252개 이상, 최근 252거래일 가격 관측률 95%·양의 거래량 관측률 90% 이상, 최근 63거래일 거래대금 관측 42개 이상과 평균 $5M 이상이다. 최근 252거래일 중 절대 일수익률 80% 초과 관측이 있는 종목도 제외한다. 유효 거래량이 없는 가격은 유효 관측으로 사용하지 않는다. 누락 자료를 합성 가격으로 채우지 않는다.

## 가격과 거래량의 구분

| 필드 | 의미와 사용처 |
|---|---|
| `prices` | Yahoo `Adj Close`. 분할·배당 조정 총수익 가격이며 수익률과 회계에 사용한다. 배당을 다시 현금 수익으로 더하지 않는다. |
| `provider_close/open/high/low` | `auto_adjust=False`로 받은 공급자의 분할 조정 OHLC 원본이다. |
| `provider_volumes` | 공급자의 분할 조정 거래량 원본이다. 배당 배수로 조정하지 않는다. |
| `raw_close/open/high/low` | 분할 이력으로 복원한 거래 당시 OHLC다. `raw_close`가 $5 가격 조건의 기준이다. |
| `volumes` | 같은 분할 배수로 역복원한 거래 당시 거래량이다. |
| `split_close` | 가격 위치·추세용 공급자 분할 조정 종가다. |
| `split_open/high/low` | 공급자 분할 조정 OHLC에 `shape_valid`를 적용한 팩터 입력이다. |
| `dividends`, `splits` | 공급자 기업행동 자료다. 배당 금액은 공급자 기준으로 보존하며 별도 재투자 수익을 만들지 않는다. |

날짜 `t`의 복원 배수는 **t 이후**의 분할 비율 곱이다. 분할 당일 비율은 당일 가격에 곱하지 않는다.

```text
F[t] = product(split_ratio[s], s > t)
as_traded_OHLC[t] = provider_OHLC[t] × F[t]
as_traded_volume[t] = provider_volume[t] / F[t]
```

따라서 거래대금은 양쪽 기준에서 같다. 0은 분할 없음이며 음수·무한대 비율, 관측 가격에 대응하는 기업행동 필드 누락은 오류다. 새로운 과거 종료일 수집도 공급자의 현재 조정 시점까지 기업행동을 확보하고 복원한 뒤 요청 기간으로 자른다. 출력 종료일 이후의 분할은 메타데이터에 남긴다.

실자료 대조에서는 AAPL 2020-08-28의 공급자 종가 약 $124.8075·187,630,000주가 거래 당시 약 $499.23·46,907,500주로, NVDA 2024-06-07의 약 $120.888·412,386,000주가 약 $1,208.88·41,238,600주로 복원됐다. 배수와 적용일은 [Apple 분할 이력](https://investor.apple.com/dividend-history/default.aspx), [NVIDIA의 SEC 신고](https://www.sec.gov/Archives/edgar/data/1045810/000104581024000144/nvda-20240607.htm)와 대조했다. 거래량의 공급자 분할 조정 기준은 [yfinance 유지관리자 설명](https://github.com/ranaroussi/yfinance/issues/2929)과 [Matplotlib 공식 문서](https://matplotlib.org/1.5.1/Matplotlib.pdf)를 확인했다. 수치와 출처는 [복원 검증 기록](../../outputs/integration/as-traded-evidence.json)에 있다.

## 자료 없음과 OHLC 격리

최종 입력에서 사용 가능한 가격이 없는 종목은 **36개**다. 공급자 조정가격을 받지 못한 31개와 양의 거래량을 동반한 가격이 전혀 없는 APGE·ATAI·BLFS·CCO·SKYT 5개를 구분해 기록했다. 후자도 종목별 두 차례 추가 조회했으며 결과는 [재시도 영수증](../../outputs/integration/quality-retries/receipts.json)에 남겼다. 이 종목들은 합집합에서 삭제하지 않는다. Best 추가 95종목은 모두 관측 가격을 확보했고, 최종일에는 53종목이 공통 적격성을 통과했다. 전체 최종일 적격 종목은 2,310개다.

원본 OHLC에서 발견한 범위 모순 13건은 수정값을 만들지 않았다. `quarantinedOHLC`에 날짜·종목·원본 값·사유를 기록하고, `shape_valid`를 통해 해당 행의 시가·고가·저가를 필요로 하는 계산에서 제외한다. 관측 종가와 총수익 가격은 별도 종가 입력 계약으로 유지한다. 이는 모순된 행의 종가가 독립적으로 검증됐다는 뜻은 아니다.

최종 품질 스냅샷은 이전 스냅샷의 **14개 행렬을 바이트 단위로 보존**하고 품질 마스크와 메타데이터만 추가했다. 따라서 실제 극단 수익을 임의로 완화하거나, 결측 종목의 포지션을 과거 현금 수익으로 바꾸지 않는다.

## 재현성과 검증 범위

- 스키마는 `integrated-market-v3`, 복원은 `yahoo-split-inversion-v1`, 품질 처리는 `observed-OHLC-quarantine-v1`이다.
- 각 행렬의 SHA-256과 전체 manifest의 입력 ID를 읽을 때 검증한다. 완료된 경로를 덮어쓰지 않으며 변경된 입력은 새 스냅샷으로 만든다. `parentSnapshotId`로 원본·복원·품질 스냅샷을 연결한다.
- XNYS 달력(`exchange_calendars 4.13.2`)과 전체 관측일을 대조했다. 기대 거래일과 실제 거래일이 모두 4,223개로 누락·추가가 없다.
- [최종 데이터 검증](../../outputs/integration/data-validation.json)은 해시·달력·합집합·누락 분류·OHLC 격리·거래대금 보존·분할 경계를 검사하며 `passed: true`다. [품질 처리 전 발견 사항](../../outputs/integration/data-validation-as-traded-prequality.json)도 남겼다.
- [기존 회계 회귀 검사](../../outputs/integration/original-parity.json)는 같은 원자료를 원래 Momentum 2,865종목으로 먼저 투영하고 기존 적격성·수식을 적용했다. 로컬 HEAD의 62개 정의에서 기존 자동 목표 생성과 새 명시적 목표 주입의 수익·NAV·비중·현금·비용·거래 상태가 정확히 일치했다. 공개 메타데이터 64개와 로컬 실행 정의 62개를 동일한 범위로 주장하지 않는다. 추가 공개 정의 두 개를 포함한 대응은 [기존 정의 원장](../../momentum_factor_lab/resources/integrated_legacy_map.json)에 있다.

거래 당시 $5 조건의 복원은 회계 회귀와 별개의 의도적인 변경이다. 과거 적격성 57,579개 날짜·종목 셀이 바뀌었고 최종일 적격 종목 수는 같았다. 이는 수익률 개선을 위한 조정이 아니라 이후 분할이 과거 가격 조건에 영향을 주지 않게 하는 수정이다.

생존 편향 보정과 과거 상장폐지 유니버스 복원은 구현하지 않는다. 현재 동결 목록을 사용하는 연구 범위를 유지하며, SEC 재무 팩터와 외부 학술 포트폴리오는 이 입력에 섞지 않는다.

## 보유 기록일과 평가일

결과의 `holdingsAsOf`는 보유 기록의 관찰일이다. 가격 결측으로 거래·평가가 보류되어도 보유 자체는 유지된다. 비중은 마지막 완전 평가의 값이므로 화면은 해당 관찰일까지 `nav`의 마지막 유효 관측일을 별도 **평가일**로 표시한다. 마지막 NAV가 미확정이면 `평가 보류`를 표시하며 기록일을 가격 평가일로 표현하지 않는다. 최초 미투자 현금 상태에는 주식 평가일을 만들어 넣지 않는다. 고정 팩터 결과의 `lastValuedDate`도 같은 가격 평가 의미다.
