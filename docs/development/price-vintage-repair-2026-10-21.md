# 조정가격 재수집에 따른 일일 역사 검증 실패

## 확인한 원인

실패 실행 39556437802와 39582839920은 동일한 소스 `7a527c71`로 동일한 2026-10-20 완료 거래일을 계산했다. 전자는 SEASON5Y의 2023-10-17~20 NAV 4건(최대 0.112456%), 후자는 REL_DOWNSIDEBETA252의 2018-11-21·23·27·28·30 NAV 5건(최대 0.112832104734%)이 0.1% 보호 기준을 초과했다. 월별 선택 팩터 변경은 없었다.

기존 진단 전용 워크플로로 마지막 정상 입력과 두 실패 입력을 다시 복원했다. 각 CSV는 진단 receipt의 SHA-256과 대조했다. 원종가·거래량·배당·분할 기록이 같은데, 조정종가의 미세한 재계산 차이만으로 다음 순위가 바뀌었다.

| 신호·일자 | 마지막 정상 입력 | 실패 입력 |
|---|---|---|
| REL_DOWNSIDEBETA252 ROKU, 2018-10-31 | 0.4078659283114803 | 0.4079014560155121 |
| REL_DOWNSIDEBETA252 MIDD, 2018-10-31 | 0.40789202186718987 | 0.4078939056638995 |
| SEASON5Y NBR, 2023-09-29 | 0.14735869252035805 | 0.14735870296481784 |
| SEASON5Y ATEN, 2023-09-29 | 0.14735879997822543 | 0.1473586215396156 |

최신 실패의 SPY 조정종가는 대조 구간에서 최대 상대 6.7373e-7만큼 달랐다. 이 차이가 시장 베타 추정과 근접 순위에 전달됐다. ROKU와 MIDD의 목표비중이 각각 약 0.304348%p 바뀌었다. 앞선 실패에서도 NBR·ATEN 비중이 같은 크기로 바뀌었다. 이는 입력 빈티지에 의한 재현성 오류이며, 순위나 NAV 임계값을 넓혀 처리하지 않는다.

## 수정과 보호 경계

- 해시로 연결된 이전 계산 입력의 과거 조정가격과 결측 상태를 보존한다.
- 신규 거래일은 동일 수집본 내 경계 수익률로 연결한다. 새 원본과 계산용 빈티지를 별도로 보관한다.
- 과거 원종가·거래량·배당·분할·달력·결측 변경을 발견하면 계속 중단한다.
- 기존 팩터 레지스트리·설정·순위·NAV 검증·소스 경합·정상 결과 보존은 변경하지 않는다.
- 캐시 경로 버전을 유지하면서 새 입력 빈티지를 다음 예약 실행에 전달한다.

`tests/fixtures/price-vintage/provenance.json`에 원 캐시 ID, 원본 스냅샷 ID, 진단 실행 ID, 파일 해시를 기록했다. 회귀검사는 실제 두 순위 역전을 재현하고 입력 고정 후 이전 순위가 복구되는지 확인한다. 별도 검사에서는 원 실패 NAV가 기존 0.1% 게이트를 계속 실패하는지 검증한다.
